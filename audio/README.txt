公開音声ページのたたき台（フォルダ構成の説明）
=================================================

■ 入っているもの

audio/
├── index.html            公開音声トップ（鉄道会社の一覧）
├── company-a/            鉄道会社A
│   ├── index.html        会社Aのページ（路線の一覧）
│   ├── line-1/           路線1
│   │   └── index.html    路線1のページ（駅別・車両別の一覧）
│   └── line-2/           路線2
│       └── index.html
├── company-b/
│   └── index.html
└── company-c/
    └── index.html


■ 使うときの手順

1. このフォルダ（audio）を、サイトのフォルダ（index.html や about.html がある場所）に
   そのまま置きます。GitHubなら、アップロード画面に audio フォルダをドラッグ&ドロップ。

2. GitHubの仕様で「空のフォルダ」は置けません。中に index.html があるので大丈夫です。

3. トップページと自己紹介ページのヘッダーに、次の1行を足すとメニューから行けます。

   <a href="audio/index.html">公開音声</a>

   （"自己紹介" のリンクのとなりに置くと分かりやすいです）


■ 音声ファイルの置き場所

路線のページ（line-1/index.html）と同じフォルダに、mp3を置きます。
例：audio/company-a/line-1/st-01.mp3

ページに書くときは、ファイル名だけでOKです。
   <audio controls preload="none" src="st-01.mp3"></audio>


■ 名前について

フォルダ名は半角英数字（ローマ字）にしておくのがおすすめです。
日本語のフォルダ名も動きますが、URLが %E3%81%82… のように長くなります。


■ 増やすときのコツ

・会社を増やす  → audio/ の中に company-d/ を作り、index.html を置く
・路線を増やす  → 会社のフォルダの中に line-3/ を作り、index.html を置く
・駅を増やす    → 路線のページの <article class="clip"> をコピーして、駅名とファイル名を変える
・ページを増やすときは、既にあるファイルをコピーして中身だけ書き換えるのが一番ラクです。
  （ヘッダーやメニューの相対パスを書き直す手間が減ります）


■ 音声ファイルの容量

GitHubは1ファイル100MBまで、リポジトリ全体は1GBくらいまでが目安です。
1つあたり1〜3MB（mp3 128kbps くらい）に抑えておくと扱いやすいです。
